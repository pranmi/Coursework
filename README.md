# Class work
A collection of courework/projects done for classes

## Final Projects:
### [Database Design (Library Database System)](https://github.com/pranmi/CS6360Project)
Implimented a simple database for a library. Started from specifications to design an *Extended Entity Relation* model, mapped it to a *Relational Model*, and normalized functional dependancies.
Then used the final models to impliment the tables, queries, and views in **OracleDBMS**

### [Computer Networks (CLI P2P File Transfer)](https://github.com/ryanpolasky/CS4390-Project)
Implimented a peer-to-peer file transfer program in python with a single tracker server and numerous peers.
Worked on features including incomplete file chunk detection/tracking, auto resume incomplete downloads, multithreading chunk requests, and the final demo script.

### [Intelligent System Analysis (Deep Learning Model)](https://github.com/pranmi/Coursework/tree/main/Matlab%20deep%20learning)
Created a small **Deep Learning** model to predict a car's safetly based on different attributes.
Implimented the model in **MatLab** using a batch gradient descent algorithm with a few layers of hidden units.
Experimented with different reularization parameters as well as hidden node pruning to improve performance.

### [Computer Graphics (Interactive Solar System Rendering)](https://github.com/Ryanjones0911/UTD-Graphics-Final-Project)
Worked alongside a team of three to impliment a rendering of the Solar System using **WebGL** with the **JavaScript Three.js** library with **Node.js** as the runtime.
Personally implimented:
- Time scale (speed up and slow down) controlls
- Clickable objects (camera tracking and showing an info panel formatted with css)
- Ellipsoidal motion for a comet with a simulated comet trail
- Dynamic shader for the sun utilizing brownian motion to mimic the surface of the sun

### [High School AP Computer Science (2D Unity game)](https://github.com/pranmi/Coursework/tree/main/Unity%202D%20shooter/2D%20jumper)
Made a small 2D platformer/shooter using **Unity** and **c#** as the scripting language. 
Implimented character movement, as well as object collision and interaction.
